# phishing-email-analysis

A hands-on SOC project focused on analyzing phishing emails,
identifying indicators of compromise (IOCs),
and documenting investigation findings.


## Objectives

- Analyze email headers
- Inspect URLs and domains
- Analyze suspicious attachments
- Review SPF, DKIM, and DMARC results
- Map phishing techniques to MITRE ATT&CK
- Write a report for each investigation


## Tools

- Thunderbird / Outlook
- VirusTotal, AbuseIPDB
- URLScan
- CyberChef
- MXToolbox
- MITRE ATT&CK


## Skills

Email Analysis | IOC Extraction | Phishing Detection |
OSINT | Email Authentication | MITRE ATT&CK
